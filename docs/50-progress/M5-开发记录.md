## 2. 问题与解决

| # | 问题 | 根因 | 解决 | 回归/备注 |
| --- | --- | --- | --- | --- |
| DEF-001 | P1：SQL 采集 DECIMAL 损坏（`[53 50 48...]` 入库） | 驱动 DECIMAL 返回 `[]byte`，`fmt.Sprint` 无特殊处理 | `collectors.go` 新增 `formatSQLValue` + 单测 | e2e M5_SQL 520.1 正确落库 |
| DEF-002 | P1（安全）：8 端点数据权限越权 | 处理器未接 sys_data_scope | 新增 `internal/pkg/scope`，data/metric/flow/dashboard 全量接入 | sec 011a~l 全过 |
| DEF-003 | P2（安全/可观测）：AI 审计因非法 UTF-8 丢失 | `masking.Digest` 未归一编码；写库错误被 `_ =` 吞 | `strings.ToValidUTF8` + rune 边界截断；`audit()` 写库失败 `log.Error` | sec 040a/b 复测过 |
| DEF-004 | P1（安全）：沙箱 RLIMIT_AS/CPU/FSIZE/NPROC 从未生效（1.1GB 分配成功，有打爆宿主机风险，疑似 WSL 两次崩溃诱因之一） | `sandbox.py` 先装黑名单 finder 再 `import resource`，被自己拦截，ImportError 被吞 | `import resource` 提前至模块顶部（finder 安装前） | worker 容器实测 1.1GB→MemoryError；S8b PASS |
| DEF-005 | P2：大盘"今日采集失败数"KPI 恒 0 且每次请求刷 ERROR 日志 | KPI 查询 `collect_task_log JOIN capacity_metric` 中 `status` 列歧义（SQLSTATE 42702），错误被静默忽略 | `routes.go` 列名限定；e2e 增加 DB 对账断言 | 修复后 KPI=10=DB 实数；e2e 断言启用 |
| DEF-006 | P3：任务日志 `duration_ms` 恒空（151/151） | `finishTask`（execute 内持久化）先于 `Run()` 对 `DurationMS` 赋值 | `engine.go` 每次 doAttempt 后即时计算 | 新任务 duration_ms=304>0 |
| TOOL-01 | 造数脚本 3 处 SQL 错误（NOT NULL 列缺失/第 101 系统外键/`make_interval` 参数名） | 脚本与 DDL 不同步 | 修脚本 3 处 | 千万行造数 181.4s 通过 |
| TOOL-02 | perf_test 3 处缺陷（缺 `global TOKEN` 全量 401/`/scripts` 列表解析/S7 异步计时测到 sleep） | 测试脚本自身问题 | global 声明/列表兼容/以 `daily_summary_log` 完成标记真实计时 | 压测 15/15 |
| TOOL-03 | WSL 引擎两次崩溃（0xC00000FD，千万行造数+日汇总并发期间）；`docker logs` 轮转后冻结 | dev 宿主 16GB/4 线程资源受限；DEF-004 未生效时沙箱内存无上限放大风险 | 压测/造数串行；WSL 恢复流程（shutdown→重启 Docker Desktop→compose up）；生产按运维手册配置 | 见《部署与发布手册》上线检查单 |
| TOOL-04 | sec_test 首跑 30/40（漏 token/角色缺 4 个 view 权限/残留数据致硬编码期望失效/seclbrute 停用） | 测试幂等性不足 | 补 token/权限幂等/动态期望值/用例前置恢复 | 复跑 40/40 |
| TOOL-05 | 试点种子以普通用户建库被 MariaDB 拒绝（1044） | 普通用户无 CREATE DATABASE 权限 | root 建库 + GRANT（幂等） | 种子重跑 PILOT SEED OK |
| TOOL-06 | 种子容器状态检查在 Windows cmd 下 `^` 被转义失效 | cmd 转义字符 | 去 `^...$` 锚定 | 状态判断正确 |
| TOOL-07 | S8c 首跑 NA（超时任务 23 分钟才终态，测试仅等 100s） | FR-COL-31 超时亦重试（3 次×60s 间隔）+ 300s 单次预算 → 全链 23min；另发现直接 SQL 改 sys_param 绕过后端 30s 参数缓存（首个 attempt 用旧值） | S8 阶段经管理 API 临时调 `flow_timeout_seconds=60`（主动失效缓存热生效）+ 等待预算 550s + 断言放宽为"timeout 或 failed+超时说明"（FR-COL-33"超时强制终止并记为失败"两种终态） | S8c PASS；300s 口径全链 1380s 实测与预算精确一致（任务 152） |
| TOOL-08 | 压测沙箱指标挂 M5_SYS，污染 sec 水平越权期望集（011g/k/l 37/40） | 压测与功能测试共用 M5_SYS 系统 | 沙箱指标迁独立系统 PERF_SB_SYS + 011g/k/l 改动态归属断言 | sec 复跑 40/40 |
| 环境坑 | 后端容器时钟 UTC 无 `date` 命令；调度器重启补跑前业务日汇总会写 10 月 missing 行；`docker logs` 冻结 | dev 环境特性 | 业务日统一 `time.gmtime()`；诊断以 `daily_summary_log`/`collect_task_log` DB 为准 | 已写入测试脚本口径 |
