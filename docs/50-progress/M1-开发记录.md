## 2. 本阶段发现并修复的缺陷

| # | 缺陷 | 影响 | 修复 |
| --- | --- | --- | --- |
| 1 | `seed.go` 用 `Truncate(24h)` 归一日期，+08 时区下整表错移一天（周五标休市/周日标交易） | 交易日推导全部错误 | 改用本地午夜归一；节假日表改字符串键（消除 time.Time map 键时区陷阱）；新增 `pkg/clock.DayStart` 统一替换 8 处同类写法；新增回归测试 `TestSeedCalendarRow` / `TestDayStart` |
| 2 | 节假日 map 以 UTC `time.Time` 为键、以 +08 时间为查表键，永远不匹配 | 节假日从未被标记 | 键改 "2006-01-02" 字符串 |
| 3 | `UpdateThreshold` 在 GORM Updates(map) 之后取旧值（GORM 会回写内存结构体） | 阈值历史旧值=新值，审计失真 | 先快照旧值再更新；`ChangedAt` 显式落值 |
| 4 | `sys_operate_log.detail` 为 jsonb，模型按字符串写入被 PG 拒绝（错误被吞） | 操作日志全部丢失 | 迁移 0003 将 detail 改 text |
| 5 | 前端 `/tradingdays`、`/datasources` 路径与 API 规范（`/trading-days`、`/data-sources`）不符 | 两页 404 无数据 | 前端路径修正 |
| 6 | 前端 Admin 页字段映射错误（users 分页结构/params 字段名/displayName） | 用户/参数/日志 tab 空白或 "-" | Admin 页重写（用户/角色/数据权限/参数/日志五 tab + CRUD） |
| 7 | 迁移器仅支持单文件 0001 | 后续迁移无法执行 | `Migrate` 支持目录按文件名升序执行，migration_state 逐文件幂等 |
| 8 | worker 容器复用后端镜像 HEALTHCHECK（探测 8080/healthz）恒 unhealthy | 容器状态误报 | compose 为 worker 增加独立 healthcheck（9100/v1/health） |
| 9 | 交易日 Excel 导入 day_type 存中文原文（"节假日"） | 导出映射/筛选异常 | 导入归一化（中/英文→trading/weekend/holiday/makeup）+ 一致性校验（调休必为交易日等） |
| 10 | auth store 读取 `user` 字段（API 返回 `userInfo`）、`displayName`（API 为 `realName`） | 用户名展示丢失 | store 与 MainLayout 字段对齐 |
