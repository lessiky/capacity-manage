## 2. 问题修复清单

| # | 缺陷 | 影响 | 修复 |
| --- | --- | --- | --- |
| 1 | gofpdf 字体路径 bug: `report/generate.go` BuildPDF 原用 `os.CreateTemp` + `AddUTF8Font(绝对路径)`; gofpdf v1.16.2 内部 `addFont` 执行 `path.Join(f.fontpath, fileStr)`, fontpath 未设置时 `/tmp/...` 前导斜杠被吃掉 → Linux 上 stat 相对路径恒失败（Windows 因盘符保留被掩盖） | 日报 PDF 导出在 Linux（Docker）环境恒 500 | 改 `p.AddUTF8FontFromBytes("SimHei", "", chartimg.FontBytes())` 直接内嵌字体字节, 删临时文件与 `os` import; 新增回归测试 `internal/report/pdfrepro_test.go` |
| 2 | Worker CAP_INPUT 双重编码: `backend/worker/run_worker.py` 原 `json.dumps(req.get("input"))` 把已是 JSON 字符串的 input 二次编码 → 清洗脚本 `json.loads` 得到 str → AttributeError | Python 流程采集/清洗调用恒失败, 第三类采集方式（Python）不可用 | `isinstance(raw_input, str)` 直接透传, 否则 dumps 一次 |
| 3 | AI 审计耗时恒 0: `internal/ai/handler.go` audit 未记录实际耗时 | FR-AI-04 审计日志 latency_ms 恒 0, 无性能审计价值 | audit 增加 `latencyMS int64` 参数, assistant/flow_gen/clean_gen 三处传 `time.Since(start).Milliseconds()` |
| 4 | 报表错误不可观测: `internal/report/handler.go` Export/Generate 失败仅回错给调用方, 无服务端日志 | 导出失败黑盒, 无法排查 | 失败路径补 `h.log.Error` |
| 5 | 报表采集数据权限: GORM `db.Raw(...)` 之后链式 `.Where` 不生效 | 按链式写法 scope 条件静默丢失, FR-RPT-14 失效 | `CollectDaily` 将 `AND m.system_code IN ?` 动态拼入 Raw SQL（systemCodes 为 nil 表全部, 供自动生成/平台管理员） |
| 6 | Go 1.26.5 embed 行为变化: `//go:embed` 不再计为使用 `embed` 包, 未使用的 `embed` import 直接编译报错（"embed" imported and not used） | chartimg 包编译失败, 字体/图表资源无法打包 | `internal/pkg/chartimg` 保留 `embed` import 并补显式引用 `var _ = embed.FS{}`; 字体 `font/SimHei.ttf` 与图表 PNG 渲染统一走该包 embed |
| 7 | E2E 环境坑: 后端容器时钟为 UTC 且无 `date` 命令 | 脚本无法直接取业务日 | e2e 用 Python `time.strftime("%Y-%m-%d", time.gmtime())` 计算 UTC 业务日 |
| 8 | E2E 环境坑: 调度器启动补跑已过的 3:00 UTC cron, M4 流程原 cron 被补跑, 污染缺数断言 | 缺数断言不稳定 | M4 流程全部用 `NEVER_CRON="0 3 30 2 *"`（2 月 30 日, 永不触发）; 重跑时先 psql 归一化旧 cron |

## 5. 遗留与 M5 衔接

- AI 依赖外部 LLM 服务（适配器模式, 已具备 50300 降级与友好提示）；生产接入需行内/经授权大模型, 生成内容默认草稿, 必须人工审核 + 预览试跑后生效（FR-AI-03 "仅供参考"）
- 平台自检当前为"手工刷新", M5/二期可加定时巡检与自检异常告警
- `GET /ai/logs` 限最近 200 条, 无分页/时间筛选；审计量增长后二期补分页
- `report_result.report_type` 预留周报/月报类型（二期）, 本轮仅日报；报表文件落本地存储（store 抽象, 可切对象存储, M5 运维项）
- echarts chunk >1MB 构建警告（vite）, 二期按需拆分（动态 import/echarts 模块裁剪）
- M5 衔接：大盘/报表数据基础就绪（水位/级别/缺数状态全链路落地）, "超线 → 告警（M3）→ 日报清单（本轮）"可直接用于试点 UAT 演示
