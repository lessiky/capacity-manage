## 3. 实现要点

### 3.1 AI 辅助预测与降级

- `ApplyAIAdjustment` 对斜率、截距和置信度调整做硬边界校验；越界或非法 JSON 不改变主指标。
- ETA 偏移超过基础窗口 50% 时，只展示为 AI 建议，统计 ETA、风险清单和报表主指标不被覆盖。
- `forecast_ai_adjustment` 保存统计基线、调整后快照、原因、耗时和错误摘要，支持回滚与前后对比。
- 本次真实联调中行内 AI 网关返回 `401`，系统记录 `aiStatus=invalid`、保留统计预测曲线并生成降级提示；没有把该结果写成“AI 修正成功”。

### 3.2 事件因子

- 草稿只有人工确认后才参与预测；修改事件会生成新版本，旧版本保留 `supersededBy` 链。
- 过期事件不再进入预测，重算后 `eventFactorVersion` 为空。
- 事件集合内容摘要作为预测输入版本，保证相同数据、事件和模型版本可复现。
- 查看按系统数据权限过滤，写入要求 `forecast:event:manage`，并记录 `forecast` 模块操作审计。

### 3.3 开放 API 与签名

- Key 格式为 `{keyId}.{secret}`，数据库只保存 `sha256(secret)`，明文仅在创建或轮换时返回一次。
- scope 支持 `data:read`、`forecast:read`、`alert:webhook`；Key 可限定系统范围并配置每分钟限流。
- 开启请求签名后必须携带：
  - `X-Cap-Timestamp`
  - `X-Cap-Nonce`（16~128 字符）
  - `X-Cap-Signature`
- 规范化字符串固定为：

```text
timestamp
nonce
METHOD
path
rawQuery
sha256(body)
```

- 签名算法为 `hex(HMAC-SHA256(secret, canonical))`；时间窗 5 分钟，Redis `SETNX` 保存 nonce 10 分钟。
- 正确签名、nonce 重放、错误签名和超窗时间戳均已用真实 HTTP 请求验证。

### 3.4 归档与扩展项

- `ArchiveDue` 只统计本次实际压缩成功的分区；已成功归档的分区幂等跳过，不再虚增计数。
- 归档文件为 gzip JSON Lines，`metric_archive_index` 保存指标、业务日、文件引用和偏移。
- 衍生指标使用受限表达式解析器试算；批量导入支持 CSV 或 JSON 数组并返回逐行失败原因。
- 转换规则支持 scale/offset/clamp/regex/expr；日历检查返回全年期望天数、实际天数和缺失日期。

### 3.5 开放 API 管理页面

- 开放 API 管理页支持 Key 创建、轮换、scope/系统范围/限流配置、请求签名开关和调用审计查看。
- 页面联调时发现 [OpenApiAdmin.vue](../../frontend/src/views/OpenApiAdmin.vue) 使用错误的系统列表地址 `/api/v1/business-systems`，导致浏览器发起 404 请求，系统范围下拉框为空。
- 已按一期既有接口契约改为 `/api/v1/systems`，并携带 `page=1&pageSize=500` 获取可选系统。
- 修复已纳入前端生产构建和 Playwright 页面回归；系统范围下拉实际加载 M5/M6/M7/M8 等系统选项。
