## 1. 测试策略

- **表驱动 + 固定时间线**：告警规则用固定策略与固定日期做表驱动测试，不依赖系统当前时间；
- **规则覆盖**：每条规则必须覆盖命中、未命中、边界命中、缺数、异常、同日多次、连续中断、窗口跨月；
- **历史重放**：用历史告警/日数据重放，确认级别映射与升级判定正确；
- **端到端**：每个里程碑一条全链路脚本（`e2e_m6.py` / `e2e_m7.py` / `e2e_m8.py`），配套回归历史里程碑；
- **真实通道演练**：M6 前完成一次真实 IM 与邮件演练（SMTP 真实投递 + 至少一种 IM 送达）。

## 3. M6 告警闭环测试

对应 Task 1~5、Task 11 Step 1；执行脚本 `e2e_m6.py`。

### 3.1 累积升级与重放

| 用例 | 步骤 | 期望 |
| --- | --- | --- |
| M6-UT-01 首次命中 | 指标首次超预警线 | 创建 **P3**，`source_line=warn` |
| M6-UT-02 同日多次 | 同一业务日重复超线 100 次 | 仅计 1 个命中日，级别不因日内次数直接升级 |
| M6-UT-03 连续升级 | 连续 3 个自然日超预警线 | P3 → **P2**，产生一条升级通知 |
| M6-UT-04 窗口升级 | 最近 7 天内有 3 天超预警线 | P3 → **P2** |
| M6-UT-05 危险线升级 | 连续 2 天超危险线 | P2/P3 → **P1** |
| M6-UT-06 缺数中断 | 连续序列中出现缺数日 | 连续规则中断；窗口规则仍按其他命中日计数 |
| M6-UT-07 异常不计数 | 窗口内出现异常值日 | 异常日不命中，不单独中断窗口 |
| M6-UT-08 危险日兼计 | 危险线命中日 | 同时计为预警线命中日 |
| M6-UT-09 多规则冲突 | 预警线与危险线规则同时满足 | 取目标级别最高者（P1 优先于 P2） |
| M6-UT-10 数据修正重放 | 修正某天日数据后重放 | 高于当前级别则升级；低于当前级别只写 `downgrade_suggestion`，不自动降级 |
| M6-UT-11 策略热生效 | 将 P3→P2 策略由连续 3 天改为连续 5 天 | 下一次判定立即生效，无需重启，不回写历史告警 |
| M6-UT-12 恢复优先 | 连续 `recover_days` 天低于预警线，但窗口内仍有旧危险命中 | 优先恢复；恢复后下次触发重新从 P3 开始 |
| M6-E2E-01 补采重放 | 历史补采后触发重放 | 告警 P3 → P2 → P1，`evidence_window` 记录窗口日期与命中天数 |
| M6-UT-14 多选作用域归一 | 作用域传 `[" SYS_A ","SYS_B","SYS_B",""]` | 落库为去空白、去重、保序的 `["SYS_A","SYS_B"]`；`global` 落 `[]` |
| M6-UT-15 多选作用域权限 | 作用域含 1 个不可见系统 | 整条策略拒绝（`CodeDataForbidden`）；全部可见才通过 |
| M6-UT-16 多选作用域匹配 | 指标 `SYS_A.MET_1` 对多值 `system`/`metric` 策略 | 任一元素命中即命中；全部不命中则不参与升级 |
| M6-E2E-18 多选作用域端到端 | 系统作用域选 `["M6_OTHER_SYS","M6_SYS"]`，另建优先级最高但作用域不含本系统的策略 | 含本系统的策略驱动 P2/P1 升级（`escalationPolicyId` 指向它）；不含本系统的策略即使优先级最高也不生效 |
| M6-E2E-19 作用域兼容入参 | `scopeValue` 传单个字符串、数组，或用 `scopeValues` 别名 | 三种写法都接受，响应统一返回数组 |

## 6. 执行方式

```powershell
cd backend
$env:GOMAXPROCS='2'
$env:GOFLAGS='-p=1'
go build -p 1 ./...
go test -p 1 ./...
go vet -p 1 ./...
cd ..\frontend
npx vue-tsc --noEmit
npm run build
cd ..
python e2e_m6.py
python e2e_m7.py
python e2e_m8.py
python testing\security\sec_test.py
```

> 本轮 M8 收尾按用户要求不执行 `testing/perf/perf_test.py`。开发机内存不足，50,000 指标预测批次性能必须改在生产等价环境复测，任何文档不得将现有 M5 性能结果当作 M8 门禁通过证据。
