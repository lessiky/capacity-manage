# 容量管理平台 UI 设计规范（M0 / Phase 0 交付）

> 版本 V1.0 · 2026-10-14 · 适用范围：一期全部 Web 页面（1920×1080 管理端为主，兼容 1440×900 最小宽度）
> 配套视觉稿：`ui-mockup/01-登录与主框架.html`、`ui-mockup/02-监控大盘.html`、`ui-mockup/03-报表中心.html`

## 1. 设计目标

- 运维/业务人员 5 分钟内看懂大盘：状态优先、数据次之、操作最后；
- 三级容量状态（正常/预警/危险）在任何页面以统一色值表达，形成肌肉记忆；
- 表格密集型页面（系统/指标/告警/任务）保证 1920 宽度下无横向滚动；
- 与 Element Plus 组件库默认风格兼容，仅覆写主题色，降低 M4 开发成本。

## 2. 色彩规范

### 2.1 三级状态色（全局强制）

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 正常 | `#34C759` | 正常水位、成功状态、健康数据源、已关闭告警 |
| 预警 | `#FF9500` | 80% 水位（warn 线及以上）、P1 告警、运行中任务、维护中系统 |
| 危险 | `#FF3B30` | 90% 水位（danger 线及以上）、P1 告警、失败任务、异常数据源 |

规则：
- 状态色仅用于"状态"，不用于装饰；中性信息用灰阶；
- 状态标签（Tag）：文字色用状态色，背景用 10% 透明度同色；
- 图表参考线：warn 线 `#FF9500` 虚线、danger 线 `#FF3B30` 虚线。

### 2.2 功能色与中性色

| 用途 | 色值 |
| --- | --- |
| 主色（品牌/主按钮/选中） | `#1F6FEB` |
| 深色侧边栏 | `#001529` |
| 页面背景 | `#F5F7FA` |
| 卡片背景 | `#FFFFFF` |
| 主文字 | `#303133` |
| 次文字 | `#909399` |
| 占位/禁用 | `#C0C4CC` |
| 分割线 | `#EBEEF5` |

### 2.3 图表配色

- 趋势线主色 `#1F6FEB`；多系列依次 `#34C759 / #FF9500 / #AF52DE / #5AC8FA`；
- 同一指标历史对比（当日 vs 7 日均值）：实线 vs 灰色虚线 `#909399`。

## 3. 布局规范

### 3.1 主框架

- 侧边栏：宽 210px，深色 `#001529`，Logo 区 56px；
- 顶部栏：高 56px，白底，左=当前页标题，右=用户下拉（头像+姓名+退出）；
- 内容区：内边距 16px，卡片间距 12px；
- 一级菜单（顺序固定）：监控大盘 / 业务系统 / 指标管理 / 数据源 / 采集流程 / 任务监控 / 告警中心 / 报表中心 / 交易日 / 系统管理。

### 3.2 页面栅格

- 大盘统计卡：4 等分（各占 24% 宽），卡顶 3px 状态色条；
- 图表区：2 等分（各 50%），高度 300px；
- 表格页：工具栏（标题+操作）→ 表格 → 分页（右下）。

### 3.3 关键页面版式

- **监控大盘**：统计卡行（系统数/指标数/活跃告警/今日任务）→ TOP8 水位条形图 + 30 天趋势线图 → 系统状态网格（按等级 P1/P2 系统在上）；
- **告警中心**：统计条（P1/P2/P3/P4 未关闭数）→ 筛选行（级别/状态/系统/日期）→ 告警表格 → 详情抽屉（时间线：触发/升级/认领/恢复/关闭）；
- **报表中心**：日期选择 + 导出按钮 → 日报预览（HTML 图文版式：概览表 → 各系统水位表 → 异常清单 → 建议区）。

## 4. 字体与字号

| 场景 | 字号/字重 |
| --- | --- |
| 页面标题 | 16px / 600 |
| 卡片标题 | 14px / 600 |
| 统计卡数值 | 28px / 700 |
| 表格正文 | 14px / 400 |
| 辅助说明 | 12px / 400（#909399） |

字体族：`PingFang SC, Microsoft YaHei, Helvetica Neue, Arial, sans-serif`；数字列使用等宽数字（`font-variant-numeric: tabular-nums`）。

## 5. 组件约定

- 状态列一律 `el-tag`（disable-transitions），类型映射见前端 `views` 内 `TAG_TYPES`；
- 时间列格式：日期 `YYYY-MM-DD`，日期时间 `YYYY-MM-DD HH:mm:ss`（Asia/Shanghai）；
- 数值列右对齐；水位列同时显示百分比与进度条（>80% 橙色、>90% 红色）；
- 空数据统一 `el-empty`；错误态显示错误摘要 + 重试按钮；
- 弹窗表单：标签右对齐，必填红星，提交按钮右侧（取消在左）。

## 6. 交互规范

- 列表页默认 20 条/页，可选 20/50/100；
- 关键操作（停用流程、下线系统、关闭告警、参数修改）二次确认（`ElMessageBox.confirm`）；
- 危险操作按钮用 `type=danger` 且默认收起在"更多"菜单中；
- 登录：失败 5 次锁定 15 分钟（后端控制），前端仅提示；会话 120 分钟无操作自动登出（401 拦截器跳登录页并保留 redirect）。

## 7. 可访问性与合规

- 状态色对比度 ≥ 4.5:1（白底上使用状态色文字时加深一档：`#248A3D / #C26A00 / #C4271D`）；
- 图表必须提供数据表格视图切换（M4 交付）；
- 所有导出/打印内容不含明文凭据（后端已脱敏，前端不再二次加工）。

## 8. 落地方式（M4 实施）

- `frontend/src/styles.css` 已定义 CSS 变量（`--cap-normal/warn/danger/primary/bg`），与设计色一一对应；
- Element Plus 主题覆写仅需替换 `--el-color-primary` 为 `#1F6FEB`，其余保持默认；
- ECharts 全局常量集中到 `frontend/src/theme/echarts.ts`（M4 新增），统一参考线与配色。
